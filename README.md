# PulseOps

PulseOps MVP repository.

## Stack
- Next.js (client)
- Express.js (server)
- MongoDB Atlas + Mongoose
- NextAuth.js + RBAC
- Joi, Gemini API, Nodemailer

## Local development
- Client: http://localhost:3000
- Server: http://localhost:5000
